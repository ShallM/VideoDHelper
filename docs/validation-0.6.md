# 0.6.0 安装包验收

验证日期：2026-10-26。设备为 Apple M4、24 GiB 内存、macOS 26.6.2。最低声明为 macOS 14，全部 Mach-O 的部署目标及依赖经过静态检查；**没有 macOS 14 真机或其他 M 系列实测，不能据此保证所有系统组合**。

## 自动化与运行组件

- Swift：43 项测试通过；Python：53 项测试通过。
- 新增进程生命周期测试：拒绝退出阶段的新进程；SIGTERM 无效时限时停止；完成任务及时释放输出回调持有的对象。
- 新增发行依赖测试：总是使用包内工具；包不完整时明确报错，不悄悄使用开发机 Homebrew。
- 包内 CPython 3.12.15、MLX 0.32.4、mlx-whisper 0.4.3、PyTorch 2.14.1、yt-dlp 2026.10.21、FFmpeg 9.0.2。
- 应用使用 `-I -B`，只保留包内工具与系统 PATH；不读取开发 `.env` 或用户 Python site-packages。

`validate-distribution.py` 使用本机模拟 Chat Completions，不调用付费模型：检查 177 个 Mach-O 均为 arm64，最低系统不高于 14.0；没有 Homebrew / 开发目录动态链接或运行时搜索路径，也没有指向包外的符号链接。验证包内 Metal、下载器版本、音频重采样、完整字幕整理及导出，再次执行任务不新增 API 请求、检查点内容保持不变。运行前后均核验完整签名。

## 包内转录实测

使用已有 turbo MLX 权重与本机 30 秒中文音频，不重新下载模型、不发送网络请求。包内 Python 默认设备为 `Device(gpu, 0)`，Metal 可用。

| 指标 | 结果 |
|---|---:|
| 输入时长 | 30 秒 |
| `transcribe` 调用耗时（包含模型加载） | 4.84 秒 |
| 完整 Python 进程墙钟时间 | 8.17 秒 |
| 输出 | 11 段、145 字符 |
| MLX GPU 分配峰值 | 约 2.14 GB |
| 进程最大 RSS | 约 1.06 GB |
| 进程峰值 physical footprint | 约 2.51 GB |

计时只验证新运行时的实际 GPU 推理，样本较短，不能替代长视频性能报告。模型已在本机，磁盘缓存、后台负载和首次准备时间会改变结果。历史长视频验证见 [0.3](validation-0.3.md)，总结质量与用量 A/B 见 [0.5](validation-0.5.md)。

## 打开、退出与资源释放

已完成 24 次登录窗口、12 次设置窗口开关的 `leaks --atExit --noContent` 检查，并另以无 MallocStackLogging 的正常运行方式完成 20 次登录 / 设置窗口开关。

- 正常运行采样第一轮后 RSS 约 131 MiB，第二轮后约 161 MiB，峰值约 169 MiB；空闲 CPU 0%。有缓存 / 窗口首次加载带来的增长，不能宣称内存零增长。
- 诊断工具报告 1,750 个分配、共 102,976 字节（约 101 KiB）泄漏。根堆栈为系统 AppIntents / XPC 和 AppKit / SwiftUI 无障碍对象；未见 VideoDHelper 自定义对象分配堆栈。该报告仍保留为已知限制，不把它写成“零泄漏”。
- 本轮实际修复进程被四小时超时任务持有、登录 Cookie 观察器未显式清理等生命周期问题，代码与回归测试已保留。
- 对正在请求本机延迟模型的任务执行 `⌘Q`，任务保存为 `cancelled`，原稿保留；应用和记录到的工作进程均退出。恢复结果见安装复测记录。

短期观察不能证明长期运行没有泄漏，也未覆盖所有 WebKit / 系统组件。诊断日志留在本机，公开文档只记录汇总，避免包含个人路径或进程地址。

## 安装复测记录

在 Finder 打开 DMG 后出现应用与 Applications 快捷入口；经该入口复制应用到 `/Applications`，推出映像后启动安装副本，继续先前取消的本机模拟任务，最终得到三份文字和导出文件。

验收中修复了两个安装问题：Finder 路径栏可能遮挡底部提示，已将文字上移；隐藏 `.app` 扩展名的 `SetFile` 操作会添加 FinderInfo、破坏严格签名校验，已取消该操作。构建脚本现在会挂载最终 DMG 并核验其中应用，避免仅验证打包前的副本。

最终发行文件再次核验镜像校验和、包内签名、安装副本与源包一致性。安装包约 330 MiB（Finder 十进制显示约 346 MB），展开后约 1.1 GB，不含模型与媒体。

## 签名与分发边界

使用 ad-hoc 签名；没有 Developer ID，也没有 Apple 公证。`codesign --verify --deep --strict` 通过只说明包内容一致，不能替代 Gatekeeper 的开发者身份 / 公证判断。网上下载后的首次打开可能被阻止，见 [安装说明](installing.md)。

发行包未包含开发凭据、个人任务、媒体和模型权重。第三方组件保持各自许可，FFmpeg 对应源码、构建脚本及组件清单随 Release 提供。本轮没有重新运行付费模型的三组 A/B；总结算法没有改变，质量结论仍以 0.5 报告为准。
