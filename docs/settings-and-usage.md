# 设置、模型与用量管理（0.5）

点主窗口齿轮、当前模型名称，或按 `⌘,` 打开设置。修改先成为草稿，点“保存设置”或按 `⌘S` 后生效；“撤销更改”恢复已保存的配置。通用默认值和模型选择在下一次运行生效，正在运行的任务保持开始时的配置。

## 通用

- 新任务默认值：字幕优先或强制本地转录、Turbo / Small 模型、媒体获取模式、MP4 / MKV 封装、完成后保留媒体、1 或 2 个并行模型请求。
- 阅读与外观：系统 / 浅色 / 深色、打开任务时的阅读页、13 / 15 / 17 / 19 号正文。
- 本机数据：打开工作空间目录、更新 B 站登录会话。恢复通用默认值不会清除模型配置、项目或任务。

每个任务仍可单独调整媒体和转录选项。本地转录继续使用 MLX / Metal GPU；这里的“模型服务”管理用于文字整理的 API 模型。

## 模型服务

1. 添加服务商，填写显示名称与 API 根地址。支持 OpenAI 兼容 Chat Completions；本机兼容服务器可使用 HTTP loopback 地址，远程使用 HTTPS。
2. 在连接卡填写 API Key。现有积算平台配置会自动迁移；密钥默认遮挡。
3. “同步模型”读取 `/models`，搜索并勾选需要的模型；服务商没有模型列表接口时，可以手动填写模型 ID。同步不自动切换默认模型。
4. 每个模型可设置显示名称、推理强度和价格。默认强度为低，也可选择不传强度、使用服务商默认行为。
5. “测试”发送一次很短的实际生成请求，会纳入用量；模型列表读取不计为模型生成请求。
6. “设为默认”后保存，后续任务使用该模型。默认模型不能直接移除，默认服务商不能直接停用；先选择另一个默认模型即可。

API 根地址末尾的 `/chat/completions` 或 `/models` 会规范化；自定义代理路径保留。改模型或服务商不会删除已经保存的原稿，旧任务能继续阅读。恢复总结时，检查点会按请求内容和模型配置判断能否复用。

交互参考了 [Cherry Studio 的服务商配置](https://www.cherryai.com/docs/en/pre-basic/settings/providers/)中“连接 → 模型目录 → 检查 → 启用”的流程，以及 [Open WebUI 的连接管理](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/)对服务商连接与模型的区分。这里使用原生 SwiftUI 实现，按本应用的任务流程组织。

## 价格表与费用口径

在**用量与费用 → 编辑模型价格**打开所有已保存模型的价格表。每个模型可分别填写币种、普通输入、缓存命中输入和输出单价，点**保存并计算**直接保存价格并切换到当前价格预估，无需再次点击设置页的保存。价格表只更新单价与币种，其他尚未保存的设置草稿继续保留。

每个模型支持 CNY、USD、EUR、HKD、JPY；报价单位可选**每百万 Tokens**或**每千 Tokens**。切换单位会自动换算已填写的数值，内部统一保存每百万 Token 单价。模型服务页面的文字按钮“编辑模型与价格”也可以进入单个模型编辑。

- 输入或输出价格留空：未配置，费用显示“待定价”或“—”。
- 明确填写 `0`：该项免费。负数、无穷或非数字不能保存。
- 缓存命中价格留空：按普通输入单价计价；如填入不同缓存价，必须有服务商返回的缓存 Token 数才能估算。
- 缓存输入已经包含在输入 Token 中；推理 Token 已经包含在输出中，不重复累加。

公式为：`[(输入 − 缓存输入) × 输入单价 + 缓存输入 × 缓存单价 + 输出 × 输出单价] ÷ 1,000,000`。

默认使用“调用时价格”：每个请求保存价格快照，改价不改写旧记录。切换“当前价格预估”可用**已保存**的当前价格重估仍能对应到相同服务商和模型的请求；历史快照保持不变。不同币种分别汇总，不做隐式汇率换算。

这是本机用量与费用估算，不是积算平台账单或余额。尚未接入服务商账单接口，不推测折扣、税费、最小计费单位或包月规则。初始价格表留空，由使用者手填服务商实际单价；不猜测价格。

## 用量与费用

可选今天、近 7 天、近 30 天或全部，筛选服务商并搜索任务 / 模型，查看每日 Token 趋势、按任务 / 模型汇总或逐次请求。趋势最多展示最近 90 天；汇总与 CSV 使用完整筛选范围。

顶部独立的“缓存命中统计”显示命中 Token 数、未命中输入 Token 数、按输入 Token 加权的命中率，以及返回完整缓存明细的请求数。明细表按任务 / 模型 / 逐次请求均有缓存列。命中率的分母只包括同时返回输入和缓存 Token 的有效请求，不使用请求命中率的简单平均，也不会把缺失缓存字段的请求当成零命中。输入为 0 时命中率显示“—”。

每个实际 HTTP 尝试各有一条记录，包含任务、服务商、模型、阶段、状态、耗时、API 返回用量和价格快照。HTTP 重试单独记录；模型输出截断、结构不合格但已经产生的用量也保留。本地检查点复用没有发起请求，因此不增加用量。新请求发送前就落盘；异常退出时记录仍存在，用量未知的请求不会当作免费。

输入 / 输出 / 缓存 / 推理统计只采用接口返回值，不拿文字长度猜 Token 数。没有返回的字段显示“—”；部分请求缺失时，会提示未知请求数。用量数据互相矛盾时标为异常，不计入费用。

旧任务的 `usage.jsonl` 只读汇入，按事件 ID 去重，不修改原文件。旧日志没有可靠的服务商、模型和价格信息，所以保留“历史未归属 / 历史未记录模型”，不能用现在的默认配置追溯猜测。旧版未记录的失败请求无法补回。

**任务删除（待发布）：**删除前会将任务内旧版用量保存到独立历史记录中，并保留任务标题以便查找。归档、删除、从废纸篓恢复都不会减少已经发生的用量或重复计费；现有全局请求记录继续保留。若旧日志损坏或无法保存历史副本，则停止删除并提示处理。

“导出 CSV”导出全部筛选结果，含未知字段的空值及计价方式。导出不包含 API Key、提示词或模型响应正文。

## 本机持久化

目录为 `~/Library/Application Support/VideoDHelper/`：

| 路径 | 内容 |
| --- | --- |
| `preferences.json` | 通用默认值、服务商、模型、默认选择、可编辑价格表 |
| `usage/events/<UUID>.json` | 每次实际 HTTP 尝试的状态、用量、归属、价格快照 |
| `usage/task-history/<任务UUID>.json` | 删除任务前保留的计量与标题，按事件 ID 去重（待发布） |
| `tasks/<UUID>/checkpoints/summary/usage.jsonl` | 兼容旧版的任务级响应用量 |

首次启动从旧 `settings.json` / 开发环境 `.env` 迁移；已有配置文件无法读取时保留原文件，不自动覆盖。密钥在本机私有文件中保存，文件权限 `0600`。请求记录只写计量元数据，不复制凭据或正文。
