# 开发记录

## 从链接到学习笔记

产品面向 macOS 中文视频学习，常见视频不超过30分钟，按约90分钟目标设计。首先交付三份可保存文字：原稿、精简台词和学习笔记。关键帧、画面公式识别与对话问答留作后续。

SwiftUI 提供原生界面，yt-dlp / FFmpeg 负责获取媒体。先检查已有 Whisper 环境，再接入 MLX / Metal 单一推理后端，复用权重而非重复下载。平台字幕优先，并可手动切换。

## 2026-10-25：端到端与长视频

0.2 跑通真实字幕、720p H.264 MP4、AI 整理、媒体保留和重启读取。0.3 增加项目管理，用55:43历史讲解与87:05技术精读验证转录和取消恢复。

转录窗口靠近停顿、保留上下文，再按词时间确定归属。原稿不被总结覆盖，窗口原子保存，恢复时核对哈希与修改时间。相邻文本块出现未完句或重复时，合并接缝并继承来源。

真实问题之一是“前者 / 后者”在压缩后改变顺序，导致复杂度比较颠倒。由此明确：来源合法只证明可追溯，不证明语义正确；对象、条件和后文更正需要核验。

## 2026-10-25：配置与计量

0.4 将服务商连接与具体模型分开管理。设置先编辑草稿再保存，运行保持开始时的配置。每次 HTTP 尝试保存价格快照与状态，失败 / 截断也记录实际用量。

使用反馈指出缓存统计与价格入口难找。0.4.1 增加独立缓存区及集中价格表，区分未配置、免费零价和未知用量。

## 2026-10-25：全文理解与回读

调研后保留旧流程作基线，引入紧凑输入、短稿整读与长稿全文结构。自然章节组织知识，执行预算限制请求大小。核验访问原文，跨章声明带齐来源；回读解决指定问题，避免无限循环。

验证发现并修复核验输出预算耗尽、跨章来源不全误报警、回读重复整章审查、概览丢弃疑问和恢复重复请求。短稿采用修改项输出；回读后仍存的原稿歧义受程序保护。

三组 A/B 与恢复见[0.5报告](validation-0.5.md)。两份长稿更省时省量，短稿更慢；个别数字歧义和漏提醒仍存在，不宣称语义零遗漏，也不事后手改输出提高成绩。

## 2026-10-26：独立 macOS 应用

0.6 使用固定摘要的可重定位 CPython 3.12 与完整哈希锁文件，强制选择 macOS 14 兼容的 arm64 wheels。FFmpeg 从固定源代码构建，禁用 GPL、nonfree 与自动外部依赖；以独立 LGPL 程序提供，并随 Release 提供对应源码及构建脚本。

发行包只复制应用与指定运行组件，不读取开发 `.env`，不带个人设置、会话或模型。图标、应用身份、版本号与 DMG 拖拽安装统一；现有 Application Support 目录保持兼容。

生命周期检查发现长超时任务会持有已完成进程，改为可取消的异步计时；登录窗口关闭时移除 Cookie 观察器。退出等待本应用工作进程保存检查点，再清理进程组。模拟接口与隔离数据目录用于安装测试，不消耗真实模型额度。

安装实测发现隐藏扩展名会添加 FinderInfo 并破坏包签名，已取消这一设置，并增加 DMG 内应用的自动验签；同时上移安装页底部说明，兼容 Finder 开启路径 / 状态栏。

最终二进制检查还发现上游 NumPy / Swift 工具链留下了 Homebrew 与 CLT 的运行时搜索路径；签名前移除这些构建机路径，并增加逐文件检查，防止打包环境掩盖可重定位问题。

本机没有 Developer ID，按发布选择使用 ad-hoc 签名并明确标为“未公证”。不以本机启动成功代替 Gatekeeper / Apple 公证结论。检查和已知限制见 [0.6 验收](validation-0.6.md)。

## 2026-10-28：任务归档与删除（待发布）

核实了任务菜单只有移动入口的问题。在 `codex/task-archive-delete` 分支补上归档、恢复和删除：归档保留项目归属和全部结果，收进独立列表；删除需确认，并使用系统废纸篓保留恢复路径。项目移除只解除归属，已归档任务不会被意外恢复。选中任务离开当前列表后，阅读区切换到剩余任务或清空。

删除关联检查发现旧版用量保存在任务检查点内，直接移走文件会令总用量回退。因此删除前先保存独立计量副本，按原事件 ID 去重，保留价格快照与标题。目录损坏、计量保存失败或任务仍持有后台锁时停止操作；目录提交失败时尝试从废纸篓回滚。锁检查使用实际工作进程锁，避免中断后遗留的“处理中”状态永久阻止整理。

52 项 Swift 测试与 53 项 Python 测试通过，开发应用构建成功。用隔离测试目录验证归档搜索、重启持久化、恢复项目归属、项目移除、删除取消与确认、Finder“放回原处”、归档笔记导出，以及处理中禁用与取消后归档。真实任务元数据前后指纹一致。截图与具体范围见[任务管理验收](validation-task-lifecycle.md)。本次不更改已发布版本、不打包新 DMG，等待后续发布。
