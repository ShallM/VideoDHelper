# 原始字幕独立提取与复制（build 36）

本轮只修改 B 站原稿入口，不修改 ASR 模型、录音总结、提示词或云端参数。固定代码 `59c6d4e`、本机预览 build 36；实际样本为用户当前查看的 5 分 18 秒云服务器视频。一次本地转录，不调用付费模型，不在验收期间改版重跑。

## 行为与边界

- “仅提取原始字幕”优先读取选中的平台字幕；无字幕或强制本地转录时，运行选定的本地语音模型，完成后保存到最近任务并停止。
- 原稿保存为 JSON、TXT 和 SRT，任务状态为“原稿已就绪”。关闭重开后仍能查看、复制及导出。
- “生成学习笔记”保留一键完整处理；对原稿已就绪的任务则复用原稿，独立开始总结，不重做下载或转录。
- “复制原始字幕（带时间戳）”输出标准 SRT，包含序号、起止毫秒和正文。平台字幕尚未读取时可直接读取并复制；历史任务、折叠处理选项时也有入口，成功后显示段数。
- 单独提取不读取云端配置；取消恢复仍停在提取阶段。媒体保留与清理遵从当前选择。旧任务未记录新字段时继续原来的完整流程。

## 离线检查

245 项 Python、95 项 Swift 测试通过。新增覆盖平台字幕独立保存、缺失云端配置时本地转录、取消后恢复、后续总结复用原稿且不再下载或转录。SRT 使用已有导出器与格式回读检查。

自包含包检查通过：arm64、签名、内置 Python/FFmpeg、Metal、本机模拟工作进程与恢复。该检查不替代真实 UI 或 ASR 验收。

## 安装副本的真实操作

从 `/Applications/VideoDHelper.app` 操作：直接点击复制，取得平台字幕 150 段；在临时文本编辑文稿粘贴，检查序号、毫秒时间戳与末段。随后选择强制本地转录，用已安装的 Whisper Large-v3 / Metal 单次执行“仅提取原始字幕”，125.845 秒完成，保存 141 段，状态停在“原稿已就绪”，未生成笔记。原稿复制粘贴同样包含首末段及 SRT 时间。

正常退出后确认进程结束，再从安装路径重开：同一任务和 141 段原稿正常读取，复制入口及“生成学习笔记”可用。原稿 TXT / SRT 文件均落盘；928 份既有录音产物及用量文件摘要未改变，云端新增请求为零。

本轮不额外启动付费总结；原稿继续总结不下载、不转录的调用顺序由后台模拟测试验证。未将该验证宣称为总结质量提升，也未对转录文字做人工听写质量评估。

本机唯一应用更新为 build 36，上一版 build 35 经 ZIP CRC 与可执行文件摘要验证后轮换到固定 `previous.zip`；清理候选及临时旧应用，保留本地日志和任务。代码在独立分支，PR 保持待合并，正式发行仍为 0.6.0。
