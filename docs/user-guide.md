# 使用指南

适用于 0.5.0 开发预览。首次运行前，请完成[本机构建](building.md)。

## 第一次配置

1. 按 `⌘,` 进入设置，也可点击主窗口齿轮或当前模型名称。
2. 在“模型服务”添加服务商，填写显示名称、Base URL 和 API Key。
3. 同步模型列表或手动输入模型 ID，发送一次连接测试，设为默认并保存。测试会产生少量真实用量。
4. 在“通用”中选择字幕策略、转录模型、媒体保留和总结方式。默认值影响新任务。

只接入了 OpenAI 兼容 Chat Completions。远程 API 使用 HTTPS，本机兼容服务可使用 loopback HTTP。上下文上限、特殊参数与价格需要自行确认，不能从模型名推断。

## 输入视频与登录

接受 B 站完整链接、`b23.tv` 短链接或整段分享文字。点“读取视频信息”后查看标题、作者、时长和实际可用格式。多 P 视频请提供明确的 `?p=数字` 链接，本版不会自动下载整个合集。

需要登录时点“登录 B 站”，在官方页面扫码，完成后点“使用当前会话”。应用只取得 B 站域名会话并保存到本机；不要求在聊天或 Issue 中提供密码、Cookie。账号权限、平台状态和视频类型仍会影响可访问格式。

## 文字来源与下载规格

| 选择 | 行为 |
|---|---|
| 优先平台字幕 | 有可用字幕时直接使用；没有可用字幕时本地转录 |
| 本地 Whisper | 强制由音频生成原稿，适合字幕缺失或质量不佳 |
| 仅获取笔记所需内容 | 有字幕时无需媒体；需要转录时获取音轨 |
| 同时下载音频 / 视频 | 按实际列出的轨道获取；可选清晰度、帧率、编码及 MP4 / MKV |

体积带“约”表示估算；选项来自当前视频和会话实际返回的格式。字幕无法可靠区分人工与自动时，仅标“平台字幕”。

关闭“完成后保留媒体”时，三份文字成功保存后才清理本任务媒体。失败和取消保留进度。后续也可在任务文件菜单单独清理媒体，文字仍可阅读。

## 本地转录与模型

Apple Silicon 使用 MLX / Metal GPU。Metal 不可用会停止并提示，不静默退回纯 CPU。

模型准备顺序：本应用已有 MLX 模型 → 本机 `~/.cache/whisper/` 下已校验的 Turbo / Small 权重 → 下载对应 MLX 模型。已有 PyTorch 格式权重首次需要本机转换，原文件保留，会占用额外磁盘；转换需要 PyTorch，见[构建说明](building.md#依赖与首次运行)。

音频约每四分钟一个窗口，优先在邻近停顿处切分并保留上下文，完成窗口即时保存。可选质量较高的 Large v3 Turbo 或较轻的 Small；耗时取决于芯片、录音和原稿质量。

## 总结、对照与来源

默认“全文理解与核验”：短稿整体阅读；长稿先建立全文结构，再按主题整理和回查。旧版固定分块仍可选；已存在任务的流程不随默认设置变化而切换。

打开已有任务，点“新建对照总结”，可基于相同原稿新建另一份总结。不覆盖原结果，无需再次转录，但会产生新的模型用量。

- **原始台词：**原字幕或机器转录，保留时间，不被模型修改。
- **精简台词：**按顺序去掉口头语和重复，保留实质内容。
- **学习笔记：**概览、章节、关键细节与待核对内容，每条知识点可按来源时间返回 B 站。

“核验已读 N/N 段”只说明原文段落进入核验，不表示每句话正确或没有语义遗漏。尤其要回看专业词、数字和前后更正。

## 项目与最近任务

“最近”汇集全部任务，“未归属”显示尚未分类的任务。项目旁的加号用于创建分类，右键可重命名或移除。移除项目只解除归属，不删除任务。

右键任务或点击标题旁的项目菜单可移动任务；在项目中创建新任务时自动归入当前项目。搜索匹配标题与文字来源。列表区分“全文理解 / 旧版分块”。

## 中断与恢复

取消、异常退出或 API 错误不会删除已完成的原稿和检查点。重新打开任务并继续处理，可复用已验证的下载、转录及总结阶段。

恢复使用当时保存的模型配置。改变模型、地址、提示词或相关参数会让部分总结检查点无法复用，但仍可复用原稿。正在运行的任务使用开始时的配置快照。

在途请求可能已由服务商处理，没有返回用量时显示未知。检查点复用不产生新请求，但不能保证取消中的请求免费。

## 导出与费用

工具栏可导出 Markdown、TXT 和 SRT；学习笔记的 Markdown 保留来源链接。按项目整理不改变导出内容。

“用量与费用”支持筛选并导出 CSV。顶部“编辑模型价格”可集中填写输入、缓存和输出单价，选择每千 / 每百万 Tokens，保存后自动换算。未知价格留空，明确免费才填 `0`。

缺失缓存不当作零命中，输出里的推理 Tokens 不重复累加。调用时价格与当前价格预估口径不同，详见[设置与计费](settings-and-usage.md)。
