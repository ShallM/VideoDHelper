# 使用指南

已发布 DMG 为 0.6.0。本文的录音、双工作区和思考强度新选项属于 **0.7.0 开发预览，尚未合并 `main` 或发布 Release**；0.6.0 用户看不到这些入口。首次使用请按[安装指南](installing.md)安装 DMG；需要修改代码时参考[构建说明](building.md)。

## 功能页切换（0.7.0 开发预览）

左上角功能菜单可选择“B站视频”或“录音整理”，切换的是整个工作区。两边各有自己的项目、最近、未归属、已归档和搜索；可以分别创建同名项目，不能把任务跨功能页移动。模型服务、价格和用量设置由整个应用共用。

B 站页继续使用链接框、读取信息、登录和生成按钮。录音页改为选择本地文件、设置是否区分二人、开始转录，以及后续的“整理与总结”。折叠处理面板后仍可浏览当前资料库；切页不会取消正在处理的任务，初版同一时间只执行一个处理任务。

录音快速流程：**选择 M4A / MP3 / WAV → 本地转录 → 改名、校订与回听 → 点击整理与总结 → 导出**。只做本地转录时可先跳过云模型配置，完整说明见[录音整理指南](recordings.md)。

## 第一次配置

1. 按 `⌘,` 进入设置，也可点击主窗口齿轮或当前模型名称。
2. 在“模型服务”添加服务商，填写显示名称、Base URL 和 API Key。
3. 同步模型列表或手动输入模型 ID，发送一次连接测试，设为默认并保存。测试会产生少量真实用量。
4. 在“通用”中选择字幕策略、转录模型、媒体保留和总结方式。默认值影响新任务。

只接入了 OpenAI 兼容 Chat Completions。远程 API 使用 HTTPS，本机兼容服务可使用 loopback HTTP。上下文上限、特殊参数与价格需要自行确认，不能从模型名推断。

### 模型思考强度（0.7.0 开发预览）

在“模型服务”中的具体模型卡片或模型编辑页选择思考强度并保存。设置按模型分别保留，两个功能页使用相同的模型配置；运行中的任务保持开始时的配置，下一次处理才使用更改。

| 选项 | 请求行为 |
|---|---|
| 服务商默认 | 不发送 `reasoning_effort`，由服务商决定；不等于关闭思考 |
| 低 / 高 / 最高 | 分别发送 `low` / `high` / `max`；档位越高不保证内容越准确，耗时与输出用量可能增加 |
| 中 | 通用兼容模型可选 `medium`；DeepSeek V4 不显示独立中档，请明确选择低、高或最高 |

原有默认模型配置保留 `low`。模型和代理服务未必支持所有档位；连接测试会产生实际用量，成功只证明请求被接受，无法证明服务商后台真的执行对应强度。若服务商拒绝参数，请明确改用其支持的档位或服务商默认，应用不会静默改档。

## 输入视频与登录

接受 B 站完整链接、`b23.tv` 短链接或整段分享文字。点“读取视频信息”后查看标题、作者、时长和实际可用格式。多 P 视频请提供明确的 `?p=数字` 链接，本版不会自动下载整个合集。

需要登录时点“登录 B 站”，在官方页面扫码，完成后点“使用当前会话”。应用只取得 B 站域名会话并保存到本机；不要求在聊天或 Issue 中提供密码、Cookie。账号权限、平台状态和视频类型仍会影响可访问格式。

## 文字来源与下载规格

| 选择 | 行为 |
|---|---|
| 优先平台字幕 | 有可用字幕时直接使用；没有可用字幕时本地转录 |
| 本地 Whisper | 强制由音频生成原稿，适合字幕缺失或质量不佳 |
| 仅获取笔记所需内容 | 有字幕时无需媒体；需要转录时获取音轨 |
| 同时下载音频 / 视频 | 按实际列出的轨道获取；可选清晰度、帧率、编码及 MP4 / MKV |

体积带“约”表示估算；选项来自当前视频和会话实际返回的格式。字幕无法可靠区分人工与自动时，仅标“平台字幕”。

关闭“完成后保留媒体”时，三份文字成功保存后才清理本任务媒体。失败和取消保留进度。后续也可在任务文件菜单单独清理媒体，文字仍可阅读。

## 本地转录与模型

Apple Silicon 使用 MLX / Metal GPU。Metal 不可用会停止并提示，不静默退回纯 CPU。

模型准备顺序：本应用已有 MLX 模型 → 本机 `~/.cache/whisper/` 下已校验的 Turbo / Small 权重 → 下载对应 MLX 模型。已有 PyTorch 格式权重首次需要本机转换，原文件保留，会占用额外磁盘；转换需要 PyTorch，见[构建说明](building.md#依赖与首次运行)。

音频约每四分钟一个窗口，优先在邻近停顿处切分并保留上下文，完成窗口即时保存。可选质量较高的 Large v3 Turbo 或较轻的 Small；耗时取决于芯片、录音和原稿质量。

## 总结、对照与来源

默认“全文理解与核验”：短稿整体阅读；长稿先建立全文结构，再按主题整理和回查。旧版固定分块仍可选；已存在任务的流程不随默认设置变化而切换。

打开已有任务，点“新建对照总结”，可基于相同原稿新建另一份总结。不覆盖原结果，无需再次转录，但会产生新的模型用量。

- **原始台词：**原字幕或机器转录，保留时间，不被模型修改。
- **精简台词：**按顺序去掉口头语和重复，保留实质内容。
- **学习笔记：**概览、章节、关键细节与待核对内容，每条知识点可按来源时间返回 B 站。

“核验已读 N/N 段”只说明原文段落进入核验，不表示每句话正确或没有语义遗漏。尤其要回看专业词、数字和前后更正。

## 项目与最近任务

“最近”汇集全部任务，“未归属”显示尚未分类的任务。项目旁的加号用于创建分类，右键可重命名或移除。移除项目只解除归属，不删除任务。

右键任务或点击标题旁的项目菜单可移动任务；在项目中创建新任务时自动归入当前项目。搜索匹配标题与文字来源。列表区分“全文理解 / 旧版分块”。

### 任务归档与删除（待发布）

以下功能已加入开发分支，**GitHub 上的 0.6.0 DMG 尚不包含**。

- **归档任务：**右键任务选择“归档任务”，或打开标题旁的“任务操作”菜单。任务从最近、未归属和项目列表收起，统一出现在“已归档”；原稿、笔记、媒体、检查点和项目归属保留。
- **恢复任务：**在“已归档”中打开任务或右键选择“恢复任务”。恢复后返回原项目；原项目已移除则回到未归属。归档期间可阅读、搜索和导出，继续处理或新建对照前需先恢复。
- **删除任务：**选择“删除任务…”并确认“移到废纸篓”，整个任务目录（包含原稿、笔记、检查点和任务内媒体）移入 macOS 废纸篓。应用不会删除你另行导出的文件、导入字幕的源文件、模型或其他任务。
- **恢复已删除任务：**在 Finder 废纸篓中选择该任务文件夹，右键“放回原处”，再在应用中刷新任务列表，任务显示在未归属。任务文件夹以任务编号命名，可按加入废纸篓的时间查找。清空废纸篓后的任务无法由应用恢复。归档适合仍需保留项目归属的任务。
- **用量与费用：**删除任务不冲减已经发生的用量。旧版任务检查点里的用量会先保存到独立历史记录中，和现有请求记录按 ID 去重；恢复任务不会重复计数。

最近、未归属和项目计数只统计未归档任务。“已归档”单独统计。移除项目会解除所有关联任务的归属，已归档的任务仍保持归档。在已归档列表中新建任务，会返回最近列表。

处理期间先取消并等待保存完成，再归档或删除；另一进程持有任务锁时也会阻止操作。若项目目录损坏，应用保留原文件并停止目录修改；若只是旧版用量记录无法完整读取，会停止删除，仍可先归档收起任务。实测范围见[任务管理验收](validation-task-lifecycle.md)。

## 中断与恢复

取消、异常退出或 API 错误不会删除已完成的原稿和检查点。重新打开任务并继续处理，可复用已验证的下载、转录及总结阶段。

每次开始或继续处理时读取当时保存的模型配置，运行期间保持该次配置快照。改变模型、地址、思考强度、提示词或相关参数会让部分总结检查点无法复用，但仍可复用原稿。

录音的本地转录和 AI 整理是两个阶段。已成功的转录窗口可继续复用；分人阶段只复用整阶段成功结果，若中途退出会重跑分人，保留 ASR 原稿。人工修改文字或说话人归属后，需要重新生成整理与总结；单纯改显示名称无需付费重算。

在途请求可能已由服务商处理，没有返回用量时显示未知。检查点复用不产生新请求，但不能保证取消中的请求免费。

## 导出与费用

工具栏可导出 Markdown、TXT 和 SRT；学习笔记的 Markdown 保留来源链接。按项目整理不改变导出内容。

“用量与费用”支持筛选并导出 CSV。顶部“编辑模型价格”可集中填写输入、缓存和输出单价，选择每千 / 每百万 Tokens，保存后自动换算。未知价格留空，明确免费才填 `0`。

缺失缓存不当作零命中，输出里的推理 Tokens 不重复累加。调用时价格与当前价格预估口径不同，详见[设置与计费](settings-and-usage.md)。

0.7.0 开发预览支持“全部 / B站视频 / 录音整理 / 连接测试”用量来源筛选。它只是筛选同一份全局用量记录，不会因切换工作区、归档或删除而取消已经发生的费用。纯本地录音转录和分人不产生 LLM Tokens。
