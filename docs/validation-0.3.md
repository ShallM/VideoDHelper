日期：2026-10-25。本机 Apple M4、24 GiB 内存；使用现有 MLX Large v3 Turbo 权重和 Metal GPU。音频在本机处理；只有文字发送到已配置的 `deepseek-v4.1-flash` 接口。

## 验证方法

- 使用应用实际的 `backend/worker.py`、本机登录会话和同一份 API 设置，完整处理音轨，未截短视频。
- 两条音轨依次进行 GPU 转录，避免同时抢占 GPU。开发编译和普通桌面应用仍在运行，速度是这台机器的实际观察值。
- 对转录检查点分别注入正常取消与 `SIGKILL`，在总结阶段注入 `SIGTERM`；恢复同一个任务目录。比较已完成检查点的 SHA-256 和修改时间，并核对新计算 / 复用窗口计数。
- 精简稿检查每个来源 ID 恰好覆盖一次、顺序一致；检查所有章节、关键点和疑点的引用确实存在；全文结尾与最后一个音频窗口都必须处理。
- 对照原稿抽查跨切片词语、跨总结分段叙述，以及分布在视频前、中、后段的关键概念与数字。完整章节与短概览分别保留，短概览不作为“全部细节”的替代品。

## 本轮发现与修复

1. **固定切点漏字。** 旧算法在 12:00 附近把“脸色”的“脸”遗漏：重叠窗口对同一词的时间估计略有不同，两个窗口的固定中点裁切都排除了它。改为在约 4 分钟切点前后 12 秒内寻找停顿，并保留前后 8 秒识别上下文。实际重跑恢复了“看你这脸色 / 根本不像吃过药的样子”。两个样本分别有 13、21 个内部切点，均找到停顿，没有回退到固定切点。
2. **分段笔记叙述未接完。** 同一段学医经历在相邻分块形成了一个未完句和下一条续述，而两条引用没有重叠，旧去重条件无法处理。增加对真实分块接缝的同主题接续检查；合并必须保留两个来源集合的并集及独有细节，不同主题继续独立保存。
3. **长文串行等待。** 分块整理改为最多两个并行请求；独立请求分别提交检查点，输出按原始分块顺序汇合。取消后不再派发新块，进程可以立即退出。HTTP 重试和限流处理仍有界。
4. **中断时测量不完整。** 每个完成的语音窗口立即保存耗时、处理长度、GPU 内存峰值及是否复用。恢复后的耗时只代表本次新计算，完整测量需要合并中断前后的记录。
5. **多层概览的引用范围缩小。** 实测模型把几分钟内多处事实合到一个关键点，却只给出最前面十几秒的编号。分层汇总和概览改用笔记编号；程序继承所选笔记全部来源，不让模型重新挑选少量原稿编号。另存 `overview-lineage.json` 和 `overview-links.json`，可逐条核对映射。概览引用有时横跨较长时间，详细章节保留更细的回看位置。
6. **比较对象在压缩后被说反。** 技术视频的详细笔记保留了“n 大时前者贵、d 大时后者贵”，第二层汇总却按新的排列顺序猜测对象，形成错误结论。补充分层和概览约束：输出必须自足，比较的对象、条件与方向须与来源公式一致；不能确定指代时保留公式、参数并标记待核对，不猜测大小关系。两条任务复用了已完成的转录与正文，只重新执行受影响的汇总步骤。

概览会优先保留来源后文的更正、撤回、传说限定与前后矛盾。整理流程添加的“疑似识别错误”与视频作者自己的校订说明分别处理。

最终复验中，错误的 n/d 大小比较已不再作为结论；无法确认的“前者 / 后者”被列入待核对内容，详细章节的公式与来源仍保留。两个实际工作进程均正常完成，全部引用有效；逐条比较概览引用与所选笔记来源的并集，映射完全一致。

## 项目与最近任务

- 原生界面支持新建、重命名、移除项目，以及将任务移至项目或未归属。
- “最近”显示全部任务，按任务更新时间排序；项目和未归属分别筛选，搜索匹配标题和文字来源。

- 已通过原生窗口点击验证创建、重命名、同名错误提示、任务右键 / 标题菜单移动、搜索和重启持久化。已建立“历史与人文”和“AI 与编程”，将对应既有任务归档。

## 中断恢复

- 张仲景视频：第二个音频窗口完成后直接 `SIGKILL`；继续处理时复用这两个窗口，仅计算剩余 12 个。
- 技术视频：第六个窗口完成后正常取消，约 0.63 秒结束；继续处理时复用六个窗口，仅计算剩余 16 个。
- 总结阶段：在已有六个完成分块、两个请求可并行处理时发送 `SIGTERM`，约 0.21 秒结束；继续处理复用了这六份结果。比较 SHA-256 与修改时间，并检查用量日志中这些完成块未被再次请求。
- 取消时尚未完成、尚未落盘的请求可能需要重试；恢复承诺针对已完成并验证的检查点。异常退出留下的“处理中”任务可重新打开并继续。

## 内容抽查与实际边界

张仲景样本抽查了家族伤亡数字、少年拜师与随诊叙述、王仲宣故事与史书时间冲突、坐堂行医的传说限定、六经框架、方剂数量、书籍散佚整理，以及最后几分钟的作者校订。尤其检查了后文对成书年代、任职和“黑死病使用中国疗法”等说法的争议或撤回，避免只保留视频前文的肯定表述。这里是忠实整理视频，未做医学或历史事实核查。

技术样本抽查了 Q/K/V 与按行 softmax、缩放因子与梯度、因果 mask、LayerNorm / BatchNorm 的归一化维度、FFN 的 512→2048→512 与残差约束、8 个头各 64 维、8 张 P100 与训练时长、WarmUp 4000，以及最后几分钟对统一架构、MLP / 残差不可缺少、更多数据和更大模型代价的讨论。全文章节保存了这些细节，短概览只选主要结论。复杂度比较的指代错误单独回归检查。

**仍有识别和来源局限：** 本地 Turbo 在人名、方名、英文术语和个别数字上存在同音误识，平台自动字幕也有同类问题。例如技术视频两种文字来源都出现“WMT2014 4.5 万句对”和标签平滑的可疑数字表述；本轮保留来源并要求回看，未以外部知识改写原稿。未逐字人工标注 WER，也未读取画面中的公式和代码。来源编号 100% 覆盖与上述抽查结果，不等于“语义零遗漏”或“每个数字正确”。默认仍优先使用已有字幕，用户可手动切换。
